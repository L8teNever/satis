So richtest du es ein

Das Skript läuft auf deinem PC neben Satisfactory. Es macht zwei Dinge von selbst:

  • Neue Blueprints von dieser Seite landen direkt im Blueprint-Ordner des Spiels.
  • Dein neuester Spielstand geht für die Karte auf den Server (höchstens alle 5 Minuten).
1. Python installieren (einmalig)

Von python.org/downloads laden. Wichtig: bei der Installation unten „Add python.exe to PATH“ ankreuzen. Mehr braucht es nicht, das Skript kommt ohne Zusatzpakete aus.

2. Pfad eintragen und Skript laden

Rechts den Pfad zu deinen Spielständen prüfen und auf „Skript herunterladen“ klicken. Das Skript enthält dann schon Server, Pfad und deinen persönlichen Schlüssel.

3. Starten

Die Datei satis_sync.py in einen eigenen Ordner legen, zum Beispiel C:\SatisSync. Dann dort ein Terminal öffnen (im Ordner in die Adresszeile cmd tippen) und starten:

python satis_sync.py

Das Fenster muss offen bleiben. Beenden mit Strg+C. Beim ersten Start legt es satis_sync.ini daneben an.

Nützlich
  • python satis_sync.py liste zeigt, welche Blueprints auf dem Server liegen.
  • python satis_sync.py einmal macht einen Durchlauf und beendet sich.
  • Automatisch beim Start: Win+R → shell:startup öffnen und dort eine Verknüpfung auf pythonw.exe C:\SatisSync\satis_sync.py ablegen. Dann läuft es ohne Fenster im Hintergrund.
  • Eigene Blueprints bleiben sicher: Gibt es schon eine mit gleichem Namen oder hast du sie selbst geändert, überschreibt das Skript sie nicht.
  • Neuen Schlüssel? Jeder Download erzeugt einen neuen und macht den alten ungültig. Lade also auf einem zweiten PC das Skript nicht noch einmal herunter, sondern kopiere deine fertige Datei dorthin.
  • Persönlich: Die Datei enthält deinen Schlüssel. Gib sie nicht weiter.
Wo liegen die Ordner?

Windows (Standard):

{{ win_path }}
Das ist C:\Users\<Name>\AppData\Local\FactoryGame\Saved\SaveGames. Dort liegen die Spielstände direkt in einem Ordner mit deiner Nutzer-ID, die Blueprints unter blueprints\<Session-Name>.

Zum Finden: Win+R → %LOCALAPPDATA%\FactoryGame\Saved\SaveGames eingeben.

Session-Name: Hast du mehrere Welten, trag unten den Namen deiner Session ein (so heißt der Ordner unter blueprints). Leer lassen holt die Blueprints in alle vorhandenen Session-Ordner.

Der Blueprint-Ordner entsteht erst, wenn du im Spiel einmal eine Blueprint gespeichert hast. Gibt es noch keinen und trägst du eine Session ein, legt das Skript ihn an.
